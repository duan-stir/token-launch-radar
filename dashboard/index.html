How the value is worked out

implied value = TVL × category multiple × growth multiplier × maturity multiplier

  • Category multiple. The median market-cap-to-TVL ratio of the snapshot's live-token protocols in the same category, when the category holds at least 3 comparables; otherwise the median over every comparable. Clamped to 0.02–1.50.
  • Growth multiplier. 1 + the 7-day TVL change, clamped to −60%…+120%, × 0.5.
  • Maturity multiplier. 0.60 + up to 0.40 for age, reaching the full 1.00 at 3 years; a protocol with no listing date takes the snapshot's median age.

No protocol name is ever special-cased. The same arithmetic scores every row, and the detail view shows each row's own breakdown.
